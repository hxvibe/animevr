# ANIME VR — 술식 시뮬레이터

고죠 사토루 · 료멘 스쿠나 · 이타도리 유지 · 후시구로 메구미 · 게토 스구루 · 옷코츠 유타 · 마히토 · 죠고 · 쿠기사키 노바라 (주술회전)

애니메이션 캐릭터의 기술을 직접 손으로 써보는 WebXR VR 시뮬레이터입니다.
더미를 원하는 만큼 소환해서 기술을 시험할 수 있습니다. 설치 없이 VR 기기(Meta Quest 등) 브라우저에서 바로 실행되며, **컨트롤러와 핸드트래킹을 모두 지원**합니다.

> 비공식 팬메이드 프로젝트입니다. 그래픽은 코드와 아래 3D 모델로 만들고, 효과음은 `tools/gen_sfx.py`로 렌더링한 파일을 씁니다 (참격음·영창 음성·영역 음악은 사용자 제공 파일).

## 흐름

핸드트래킹 위주로 설계했습니다(컨트롤러도 동작).

1. 첫 화면 오른쪽 위에서 **언어**(한국어 · English · 日本語)를 고를 수 있습니다 (VR 안의 타이틀 · 설정 탭에도 있음). 한글로 나오는 글만 바뀌고, 기술을 쓸 때 뜨는 일본어 기술명은 그대로입니다
2. 첫 화면에서 **VR 시작** · **MR 패스스루로 시작**(현실 방이 배경, 기기가 지원하면) · 데스크톱으로 체험
3. 모든 3D 모델(적 · 술사 무기 · 식신 · 손)과 배경 · 셰이더 준비가 끝나야 시작 버튼이 켜집니다 (덜 그려진 모델이 튀어나오지 않게)
4. 눈앞에 뜨는 **타이틀 화면**에서 캐릭터와 배경을 고르고 **시작**
   - 버튼은 손가락으로 직접 누르거나, 멀리서 **손으로 가리키고 엄지·검지를 맞대면** 클릭됩니다
5. 게임 중 메뉴(옵션)는 **열었을 때만** 나타납니다
   - **퀘스트 기본 메뉴 키**(왼손바닥을 얼굴 쪽으로 돌리면 뜨는 퀘스트의 ≡를 집기)를 누르면 옵션이 왼손 옆에 작게 열립니다 (게임 자체 아이콘은 띄우지 않음)
   - 컨트롤러 **Y** / 키보드 **H**
   - **더미 소환**: 종류(기본·사격형·돌격형·거대·샌드백∞) + 적 주령/주저사(마히토·죠고·손가락 보유자·쿠치사케온나·효수 주령·봉투 가면), 체력(50·100·300·1000·∞), 수량
   - **설정**: 배경(연습장·도시·골목·시부야·신주쿠·초원), 손목 HUD, 기술명 표시, 데미지 숫자, 플레이어 무적, 그림자, 이동(스틱·엄지척), **영역전개 손동작 켜기/끄기와 발동 버튼**, 높이 보정 (+ 캐릭터별 옵션)
   - **조작법**: 술식마다 손 모양을 3D 손이 직접 맺어 보이는 **시연 영상**이 함께 나옵니다 (핸드트래킹·컨트롤러·데스크톱 보기 전환)
   - **메인 메뉴**
6. 더미는 메뉴의 **더미 소환**에서 부릅니다 (단축키 없음)
7. **이동**: 컨트롤러는 왼쪽 스틱. 핸드트래킹은 **왼손 엄지척(👍)** — 엄지를 세운 순간의 손 위치가 기준점이 되고, 그 자리에서 손을 앞뒤·좌우로 옮긴 만큼 그 방향으로 걷습니다(멀수록 빠름). 손 자리에 기준 고리와 방향선이 보이고, 손을 펴면 멈춥니다. 오른손 엄지척을 세운 채 옆으로 7cm 밀면 30도씩 돌아섭니다 (가운데로 돌아왔다가 다시 밀기)

## 컨트롤러 = 손

컨트롤러를 쥐고 있어도 **손 모델**이 보이고, 누른 버튼에 맞춰 손가락이 굽습니다 (설정 › 컨트롤러 손 끄기 가능). 기술을 써도 손은 컨트롤러가 있는 자리 그대로이고 **손가락 모양만** 수인으로 바뀝니다.

| 누르는 것 | 손 모양 |
|---|---|
| 아무것도 | 편 손 |
| 트리거 | 집기 (엄지·검지) |
| 그립 | 검지 펴기 |
| 그립 + A(X) | 검지·중지 펴기 |
| 그립 + 트리거 | 주먹 |
| 그립 + 트리거 + A(X) | 엄지 세운 주먹 (고죠 虚式「茈」) |

Y 메뉴 · 왼쪽 스틱 이동 · 오른쪽 스틱 회전. **조작법 › 컨트롤러** 보기에는 기술마다 무엇을 누르는지 적혀 있습니다.
**게토 · 메구미**는 손 모델만 그리고 조작은 원래 컨트롤러 방식 그대로입니다 (식신·주령 부르기는 트리거).

영역전개처럼 버튼으로는 손가락을 맺을 수 없는 수인은, 비슷한 자세를 잡으면 손가락이 수인표 모양으로 바뀌며 발동합니다.

| 수인 | 컨트롤러 자세 |
|---|---|
| 고죠 無量空処 | 그립만 쥐고 컨트롤러를 얼굴 앞에 세운다 → 꼰 검지·중지 |
| 고죠 虚式「茈」 | 그립 + 트리거 + A(X) |
| 스쿠나 伏魔御廚子 | 두 손 모두 그립만 쥐고, 얼굴 앞에서 두 컨트롤러 옆면을 맞대 세운다 → 검지·약지가 접힌 염마천인 |
| 이타도리 영역 | 두 손 그립만, 가슴 앞에서 맞대 위로 |
| 마히토 自閉円頓裹 | 아무것도 누르지 않은 두 손을 가슴 앞에서 맞대고 위로 |
| 죠고 蓋棺鉄囲山 | 아무것도 누르지 않은 두 손 앞쪽을 서로 엇갈리게 (지붕) |
| 유타 真贋相愛 | 왼손 그립+트리거(주먹)를 턱 앞에, 오른손은 아무것도 누르지 않고 세워 그 앞에 |

## 쿨타임

기술마다 재사용 대기시간이 있고, 기다려야 하면 남은 초가 뜹니다. **설정 › 쿨타임**을 끄면 모두 없어집니다.
예: 고죠 茈 14초 · 스쿠나 세계참 20초 / 개 12초 / 해 2초 · 이타도리 천혈 5초 · 게토 주령 3초 / 소용돌이 12초 · 유타 주언·순애빔 · 노바라 簪 2.5초 / 공명 6초 · 죠고 화산두 6초 · 마히토 발체 7초 / 개조인간 2.5초.

## 배경

| 배경 | 내용 |
|---|---|
| 연습장 | 실내 훈련 시설 — 스포츠 고무 코트 바닥과 라인, 충격 흡수 패드 벽, 철골 트러스와 LED 조명, 높은 창, 관람창, 샌드백 · 타격 인형 · 매트 · 사물함 · 목검 걸이, 날려 보낼 수 있는 폼 블록 · 라바콘 |
| 초원 | 넓은 초원 (낮) — 바람에 물결치는 풀잎 수만 장, 들꽃 무리, 싸움터 바깥의 완만한 언덕, 흩어진 나무와 작은 숲, 먼 산, 흘러가는 구름 |
| 도시 | 도쿄 오피스가 (낮) — 유리·타일 빌딩, 가로수, 신호등, 자동차 |
| 골목 | 도쿄 뒷골목 (밤) — 초롱, 이자카야, 세로 간판, 젖은 바닥 (웅덩이는 월드 좌표 잡음이라 크기·모양이 제각각이고 반복되지 않는다) |
| 시부야 | 스크램블 교차로 (해 질 녘) — 대형 LED 전광판, 사방 횡단보도, 간판 빌딩 |
| 신주쿠 | 유흥가 (밤) — 네온 간판, 젖은 아스팔트의 반사 |
| 패스스루 (현실) | **MR 패스스루로 시작**하면 현실 방이 배경 — 바닥엔 그림자만 받는 투명 판, 영역전개를 펼치면 영역이 현실을 덮는다 |

**충돌**: 술사(플레이어)와 적 모두 벽 · 건물 · 차 · 기둥 같은 물체를 통과하지 못합니다. 가벼운 소품(상자 · 콘)은 밀려납니다.

건물 외벽·아스팔트·보도블록은 코드로 굽는 PBR 텍스처(노멀맵 포함)로 만들고, 하늘(Preetham 대기 산란) 또는 밤하늘을 환경광으로 캡처해 금속·유리에 비춥니다. 해 그림자는 플레이어를 따라다니는 그림자 지도로 그리며, 설정에서 끌 수 있습니다 (퀘스트에서 무거우면 끄기).

더미는 첨부된 테스트 더미 모델을 씁니다. 맞으면 날아가고, 쓰러지면 일어나며, 죽으면 파편으로 부서지거나 참격 방향대로 잘립니다.
**잡기·던지기**: 더미에 손을 대고 주먹을 쥐면 손에 가장 가까운 부위(머리·팔·다리 등)를 잡고, 나머지 몸은 래그돌 물리로 늘어지고 흔들립니다. 손을 펴면 손의 속도로 던집니다 (컨트롤러: 그립, 데스크톱: T). 기술에 맞아 날아갈 때도 래그돌로 움직입니다.

## 캐릭터

### 고죠 사토루 — 무하한 주술 · 육안

| 기술 | 핸드트래킹 | 컨트롤러 |
|---|---|---|
| 術式順転「蒼」 | 검지+중지로 가리키면 손가락 끝에 생성 → **손을 펴면** 창이 손을 따라 멀리 이동 | 왼쪽 트리거 |
| 術式反転「赫」 | 검지만 펴서 충전 → 찌르거나 손을 펴서 발사 | 오른쪽 트리거 충전 → 놓기 |
| 전환 · 취소 | 창 상태에서 검지만 → 혁, 혁 상태에서 검지+중지 → 창 · **주먹 → 사라짐** | — |
| 虚式「茈」 | **수인**: 검지·중지를 접고 그 위에 엄지를 얹은 채 약지·새끼를 펴기 → 왼쪽의 창과 오른쪽의 혁이 곧게 다가와 합쳐져 茈 완성 → 손을 펴거나 밀면 발사, 주먹은 취소 (양손 창+혁을 맞대도 됨) | 창+혁 유지, 컨트롤러 맞대기 → 밀기/놓기 |
| 領域展開「無量空処」 | 검지·중지를 **꼬아서** 얼굴 앞에 세우고 6초 (수인표) — 1초째부터 영창 음성이 나오고 끝날 즈음 전개 (설정에서 끄기 / 메뉴에서 발동) | 양쪽 스틱 눌러 6초 |
| 無下限 / 六眼 | 양 손바닥 앞으로 1초 / 손으로 눈을 0.5초 가리기 (추적이 끊겨도 인식) | X / A |

무량공처 연출: 결계 돔 → 화이트아웃 → 정면(좌우 방향만 따름)에서 날아오는 초공간 워프 → 섬광 → 하얀 빛을 두른 블랙홀과, 영역(구)의 겉면에서 계속 사라졌다 다시 튀는 하얀 물감 얼룩. 영역 안의 더미와 탄환은 멈춥니다. 영역전개 후 10초 재사용 대기.

### 료멘 스쿠나 — 어주자(御廚子)

| 기술 | 핸드트래킹 | 컨트롤러 |
|---|---|---|
| 解(カイ) 참격 | 편 손을 빠르게 휘두르기 (연속 가능) | 트리거(정면) / 트리거 쥐고 휘두르기 |
| 捌(ハチ) 난도질 | 편 손으로 더미를 직접 건드리기 — 약한 상대일수록 잘게 썰림 | 더미에 대고 트리거 |
| 竈(カミノ) 開(フーガ) | 한 손을 펴고, 다른 손 집게로 그 **손가락 앞**을 잡아 활처럼 당겼다 놓기 (주먹이나 손목을 붙잡은 손은 집게로 보지 않는다 — 세계참 영창과 헷갈리지 않게) | 왼쪽 그립 + 오른쪽을 왼손에 대고 트리거 → 당겼다 놓기 |
| 세계를 가르는 해 | 편 손바닥을 앞으로 뻗고 **다른 손 주먹으로 그 손목을 붙잡은 채** 1.3초(영창 龍鱗·反発·番いの流星) → 휘두르기 | 편 손(아무것도 안 누름)을 앞으로 1.3초 → 휘두르기 |
| 領域展開「伏魔御廚子」 | 얼굴 앞에서 손바닥을 마주 대고 **검지·약지는 접고 중지·새끼를 세워** 1.5초 (염마천인 · 메뉴에서도 발동) | 양쪽 스틱 눌러 1.5초 |

세계를 가르는 해는 기기에 따라 연출이 다릅니다: **PC(데스크톱·PC VR)** 는 공간이 갈라지는 지금의 연출, **단독형 VR(Quest 등)** 은 가벼운 이전 연출(거대한 초승달 참격과 선). 설정 › 세계참 PC 연출로 바꿀 수 있습니다.

영역전개 시 영창 음성이 나오고, 음성이 끝나기 0.5초 전부터 영역 음악이 흐릅니다 (영역 20초).

세계참 영창과 영역전개 수인 중에는 먹선 테두리의 핏빛 오라가 손을 감싸고, 영창이 진행될수록 점점 선명해집니다 (컨트롤러는 컨트롤러를 감쌈). 개(開)의 화살은 당길수록 굵어지지 않고 길어집니다. 개(開)의 화살은 **셀 셰이딩(애니메이션풍)으로 칠한 입체 불새** — 먹선 테두리, 날개처럼 뒤로 휘는 불꽃 혀, 머리의 흰 심, 꼬리 끝이 조각조각 끊기며 사라지고, 날아가면 셀풍 불티와 검은 연기를 남깁니다. 폭발은 실사풍 불(`src/core/realFire.js`: GPU 빌보드 불꽃·연기·불티, 흑체 색, 닫힌 식 운동)로 그립니다. 착탄하면 섬광 → 화구 → 불기둥 → 검은 연기·버섯구름 → 바닥 먼지 고리 → 불티 순으로 터지고, 바닥에 숯 같은 그을음과 잔불이 남습니다.

복마어주자는 첨부된 사당 모델이 플레이어 **뒤쪽**에 솟아오르며(뼈 무더기는 땅에 반쯤 묻힘), 안에서는 범위 안 모든 것이 해·팔에 계속 썰리고, 카미노를 쓰면 분진이 일제히 폭발합니다. 설정에서 **카미노 원작 조건**을 켜면 해와 팔을 먼저 써야 개(開)가 열립니다.

- **관우**: 앞발로 땅을 긁어 흙을 튀기다가 갤럽으로 돌진, 멈출 땐 앞다리를 내뻗어 버티며 미끄러진다
- **만상**: 떨어지며 다리를 벌리고 귀가 바람에 들린다. 착지하면 무게에 무릎이 꺾여 내려앉았다 출렁이고, 귀·코·꼬리가 관성으로 늦게 휘청인다
- **마허라**: 머리 위 법진은 바퀴 굴대(수직축)로 돈다. 뒤통수의 긴 꼬리는 스프링 사슬로 몸·머리 움직임에 늦게 따라오며 출렁인다(등에 닿으면 밀려난다). 무거운 두 발 걸음 (골반 비틀림·처짐, 착지 충격으로 철렁, 팔은 다리와 엇갈려), 내려베기는 예비동작(칼을 치켜들며 몸을 감기) → 왼발을 내딛으며 대각선으로 → 이어베기 → 회복
- **가마**: 혀를 쏘기 전 웅크리고, 쏠 때 앞으로 튀어나가듯 숙이고, 끌어올 땐 뒤로 버티며 떤다. 목주머니가 벌렁인다
- **오로치**: 몸을 따라 흐르는 S자 물결, 물어 올린 대상을 몸통으로 나선처럼 휘감아 조인다
- **탈토**: 뛰기 전 웅크리고, 공중에선 늘어나며 코를 들었다 내리고, 착지하면 납작해졌다 출렁인다
- **옥견 혼**: 네 발로 달린다 (걷기·속보·갤럽 섞기, 앞발 손가락 끝과 뒷발가락을 바닥에 맞춘다). 발톱을 휘두를 땐 몸을 일으켜 세운다

## 적 (더미 소환 → 주령 · 주저사)

- 적은 몇 초마다 **거리 계획**을 다시 골라 붙어 싸우거나(근거리) 적당히 떨어지거나(중거리) 멀리서(원거리) 그 거리의 술식을 씁니다
- **회복**: 고죠는 반전술식(빠르게, 타 버린 술식도 빨리 회복), 마히토는 무위전변으로 몸을 고치고, 주령은 천천히 재생합니다 (한동안 안 맞으면)
- **마허라 조복 의식** 중엔 적도 술사도 공격하지 못합니다

모델을 입힌 적은 가만히 있을 때 숨쉬고 무게를 옮기며 두리번거리고, 손가락은 자연스럽게 살짝 구부립니다 (때릴 땐 주먹). 능력에 맞는 공격을 여러 가지 섞어 씁니다.

### 영역 싸움 (마히토 · 죠고 · 고죠)

> 영역에 대한 가장 효과적인 수단은 이쪽도 영역을 전개하는 것. 동시에 영역이 전개되면 보다 세련된 주술이 그 자리를 제압한다. — 고죠 사토루

- 마히토(自閉円頓裹) · 죠고(蓋棺鉄囲山) · 고죠(無量空処)는 맞붙고 한참 지나거나 체력이 깎이면 수인을 맺고 **영역을 펼칩니다**. 플레이어가 먼저 펼치면 **맞영역**으로 응수합니다. 더미 소환 탭의 **적 영역전개** 버튼으로 바로 펼치게 할 수도 있습니다
- 적의 영역 안에서는 **필중**: 자폐원돈과 = 영혼을 만지는 무위전변, 개관철위산 = 계속 타들어 간다, 무량공처 = 정보가 쏟아져 몸이 굳는다(굳었다 잠깐 풀리는 틈에 영역을 펼칠 수 있다)
- 플레이어도 영역을 펼치면 **영역 싸움**. 영역 싸움의 강함은 원작 서열대로 **스쿠나 > 고죠 > 마히토 ≈ 죠고 > 메구미 > 특급 주령**(스쿠나 100 · 고죠 94 · 유타 87 · 마히토 82 · 죠고 80 · 이타도리 74 · 메구미 58 · 손가락 보유자 42)이고, 나중에 펼친 쪽 보정, 남은 주력·적의 체력이 더해집니다. **더 강하다고 무조건 이기지는 않습니다** — 격돌마다 운이 끼고, 주력을 쏟아 버티면 뒤집힐 수 있습니다
  - 차이가 아주 크면 **압도** — 낮은 쪽이 꾸준히 밀리지만, 주력을 쏟아 버티면 흐름을 늦추거나 뒤집을 수 있다
  - 비슷하면 **중첩** — 서로의 필중 효과가 사라지고(고죠의 무하한도 그대로), 두 영역의 경계가 밀고 밀리는 줄다리기. **두 손바닥을 앞으로 밀면**(컨트롤러 두 트리거 · 데스크톱 F) 주력을 쏟아 내 쪽으로 기운다. 미완성인 감합암예정도 버티면 중화할 수 있다
  - 두 영역의 경계는 두 중심 사이에서 휘어진 곡면으로, 우세에 따라 상대 쪽으로 밀려나며 일렁입니다. 1~2.4초마다 **격돌**이 일어나 경계가 크게 출렁이고 불꽃이 튀며, 맞닿은 곳에서 두 영역의 색이 섞인 빛의 막이 지지직거린다. 머리 앞 막대에 우세가 보인다
- 밀어낸 쪽: 상대 영역이 금 가며 부서지고 상대는 술식이 타 버린다(10초 동안 술식 없음 · 무하한도 꺼짐). 밀려난 쪽(플레이어): 영역이 깨지고 필중을 그대로 맞는다 — 원작처럼 거의 죽을 만큼 아프다
- 비등하게 버티다 내 영역이 먼저 닫히면 두 영역이 함께 사그라든다
- 영역 싸움 화면: 먹색 띠 위에 「領域の押し合い」, 두 영역 이름이 빛나고, 비스듬히 맞물린 두 색 막대의 이음매가 번개처럼 지지직거린다. 밀리면 시야 가장자리가 붉게 조여 오고, 격돌 순간 화면이 떨리며 「— 밀어붙였다 —」/「— 밀린다 —」. 형세 % · 주력 게이지 · 지금 할 일이 함께 뜬다
- 결계를 치는 영역이 펼쳐지면 **소품(상자 · 콘 등)은 영역 안으로 들어오지 않습니다** (배경과 함께 사라졌다가 영역이 걷히면 돌아온다). 결계 없는 스쿠나의 복마어주자는 바닥 · 하늘 · 조명을 바꾸지 않고 사당만 세운다
- **동그란 영역 밖으로 나갈 수 없습니다** — 영역 안에 갇힌 술사도 적도 경계에서 막힌다 (내 영역 · 적 영역 모두)
- **결계는 바깥에서 깨진다** — 영역 밖에서 결계(돔 표면)를 주먹으로 세게 치면 금이 가다가 부서지고, 시전자는 술식이 타 버린다 (영역은 안쪽엔 강하고 바깥엔 약하다). 영역보다 넓은 맵(초원 등)에서 써 볼 수 있다

**맷집**: 적에게는 버티는 힘(체력이 많을수록 큼)이 있어, 웬만한 주먹엔 움찔하며 밀리고 하던 공격이 끊길 뿐 쓰러지지 않습니다 (주먹마다 짧은 히트스톱과 충격파 고리). 버티는 힘이 다하거나 아주 센 일격을 맞으면 "무너졌다!"와 함께 쓰러집니다. 영역전개·茈 같은 큰 기술을 쓰는 중엔 끊기지 않습니다.

맞으면 래그돌로 쓰러졌다가 엉덩이를 축으로 무릎을 꿇고 일어섭니다. 소품(상자)과 더미는 바닥을 뚫지 않는 강체 물리로 구르고 쌓입니다.

### 공통
- **멈춤 방지**: 한 부분에서 오류가 나도 그 부분만 건너뛰고 게임은 계속 돕니다. 적 모델은 받은 뒤 셰이더를 미리 컴파일해 처음 부를 때 끊기지 않게 합니다
- **잘린 조각**: 실제로 남은 부분의 가장 낮은 점으로 바닥에 닿아 땅에 박히지 않고, 닿은 점을 축으로 넘어집니다
- **적의 움직임**: 손가락마다 굽힘이 다른 편안한 손, 몸에서 살짝 떨어뜨린 팔(손이 허리에 박히지 않게), 버릇마다 다른 걸음새 — 마히토는 흐느적거리며 팔을 크게, 죠고는 짧은 다리로 뒤뚱뒤뚱, 고죠는 주머니에 손 넣고 느긋하게, 효수 주령은 좌우로 쿵쿵. 걸을 땐 골반이 디딘 다리 쪽으로 기울고 가슴은 반대로 비틀리며 머리는 흔들림을 덜 받는다
- **주먹**: 주먹(컨트롤러는 그립)으로 더미를 치면 타격. 일정 확률로 **흑섬(黒閃)** — 히트스톱과 검붉은 번개
- **회복**: 피격 2초 뒤부터 체력 자동 회복
- 손 추적이 끊기면 쓰던 기술(창·혁·천혈 등)은 즉시 풀리고, 손 모델도 숨깁니다 (추적이 멈춘 자세나 머리 근처로 튄 자세가 남지 않게)
- 영역전개 수인·영창 등에서 손을 감싸는 오라는 위로 핥아 오르는 셀풍 불꽃(먹선 테두리 + 불티)입니다
- 기술을 쓰면 만화풍 일본어 기술명이 뜹니다 (설정에서 끄기 가능)

## 실행

WebXR은 **HTTPS**에서만 동작합니다.

- **GitHub Pages**: 저장소 Settings → Pages → `Deploy from a branch`, `main` / `(root)` → `https://<사용자명>.github.io/animevr/`
- **로컬**: `npx serve .` 또는 `python3 -m http.server 8080` 후 PC 브라우저(데스크톱 모드). Quest에서 로컬로 보려면 USB 연결 후 `adb reverse tcp:8080 tcp:8080`

손·컨트롤러 모델은 Meta Quest 기본 모델(WebXR Input Profiles, MIT)을 `assets/profiles`에 포함해 오프라인에서도 보입니다.

## 소리

- `assets/audio/sfx/`: 기술 효과음. `python3 tools/gen_sfx.py`로 다시 만들 수 있습니다 (잡음·과도음·잔향을 겹쳐 렌더링). 이름을 붙이면 그 파일만 다시 씁니다 (예: `python3 tools/gen_sfx.py poof ki_blast`). `slash.mp3`(스쿠나 참격)는 사용자가 제공한 파일입니다.
- `assets/audio/`: 영역전개 음성(고죠·스쿠나·메구미), 푸가 음성, 복마어주자 음악, 마허라 법진 회전음(`mahoraga_wheel.mp3`) — 사용자가 제공한 파일을 압축해 넣은 것입니다. 원작 음원은 저작권이 있으니 저장소를 공개 배포할 때는 주의하세요.

## 캐릭터 추가하기

`src/characters/<id>/`에 클래스를 만들고 `constructor(ctx)`, `update(dt)`, `dispose()`, `helpLines(mode)`, `hudRows()`를 구현한 뒤 `src/characters/index.js`의 `CHARACTERS`에 등록합니다. `ctx.input.left/right`에서 손 모양(`gesture`, `gestureTime`), 위치·방향·속도(`pos`, `dir`, `palm`, `vel`, `speed`), 버튼(`btn`, `pressed()`)을 읽고, `ctx.world.forEachTarget()`으로 더미와 소품에 `impulse()`·`damage()`를 주면 됩니다. 선택: `meleeHit()`(주먹 타격을 직접 처리), `castDomain()`·`cancelDomain()`·`domainLabel`(영역전개 자리의 궁극기), `reviveText`(쓰러졌을 때 문구), `handBusy(side)`(잡기 막기).
