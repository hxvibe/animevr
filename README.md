# ANIME VR — 술식 시뮬레이터

고죠 사토루 · 료멘 스쿠나 · 이타도리 유지 · 후시구로 메구미 (주술회전) · 우즈마키 나루토 (나루토) · 손오공 (드래곤볼)

애니메이션 캐릭터의 기술을 직접 손으로 써보는 WebXR VR 시뮬레이터입니다.
더미를 원하는 만큼 소환해서 기술을 시험할 수 있습니다. 설치 없이 VR 기기(Meta Quest 등) 브라우저에서 바로 실행되며, **컨트롤러와 핸드트래킹을 모두 지원**합니다.

> 비공식 팬메이드 프로젝트입니다. 그래픽은 코드와 아래 3D 모델로 만들고, 효과음은 `tools/gen_sfx.py`로 렌더링한 파일을 씁니다 (참격음·영창 음성·영역 음악은 사용자 제공 파일).

## 흐름

핸드트래킹 위주로 설계했습니다(컨트롤러도 동작).

1. 첫 화면에서 **VR 시작** (또는 데스크톱으로 체험)
2. 눈앞에 뜨는 **타이틀 화면**에서 캐릭터와 배경을 고르고 **시작**
   - 버튼은 손가락으로 직접 누르거나, 멀리서 **손으로 가리키고 엄지·검지를 맞대면** 클릭됩니다
3. 게임 중 메뉴(옵션)는 **열었을 때만** 나타납니다
   - **퀘스트 기본 메뉴 키**(왼손바닥을 얼굴 쪽으로 돌리면 뜨는 퀘스트의 ≡를 집기)를 누르면 옵션이 왼손 옆에 작게 열립니다 (게임 자체 아이콘은 띄우지 않음)
   - 컨트롤러 **Y** / 키보드 **H**
   - **더미 소환**: 종류(기본·사격형·돌격형·거대·샌드백∞), 체력(50·100·300·1000·∞), 수량
   - **설정**: 배경(하얀 방·도시·골목·시부야·신주쿠), 손목 HUD, 기술명 표시, 데미지 숫자, 플레이어 무적, 그림자, 이동(스틱·엄지척), **영역전개(나루토는 구미 모드, 오공은 초사이어인) 손동작 켜기/끄기와 발동 버튼**, 높이 보정 (+ 캐릭터별 옵션)
   - **조작법**, **메인 메뉴**
4. **B 버튼 / R 키**: 선택한 더미를 바로 소환
5. **이동**: 컨트롤러는 왼쪽 스틱. 핸드트래킹은 **왼손 엄지척(👍)** — 엄지를 세운 순간의 손 위치가 기준점이 되고, 그 자리에서 손을 앞뒤·좌우로 옮긴 만큼 그 방향으로 걷습니다(멀수록 빠름). 손 자리에 기준 고리와 방향선이 보이고, 손을 펴면 멈춥니다. 오른손 엄지척을 세운 채 옆으로 7cm 밀면 30도씩 돌아섭니다 (가운데로 돌아왔다가 다시 밀기)

## 배경

| 배경 | 내용 |
|---|---|
| 하얀 방 | 기본 연습장 |
| 도시 | 도쿄 오피스가 (낮) — 유리·타일 빌딩, 가로수, 신호등, 자동차 |
| 골목 | 도쿄 뒷골목 (밤) — 초롱, 이자카야, 세로 간판, 젖은 바닥 |
| 시부야 | 스크램블 교차로 (해 질 녘) — 대형 LED 전광판, 사방 횡단보도, 간판 빌딩 |
| 신주쿠 | 유흥가 (밤) — 네온 간판, 젖은 아스팔트의 반사 |

건물 외벽·아스팔트·보도블록은 코드로 굽는 PBR 텍스처(노멀맵 포함)로 만들고, 하늘(Preetham 대기 산란) 또는 밤하늘을 환경광으로 캡처해 금속·유리에 비춥니다. 해 그림자는 플레이어를 따라다니는 그림자 지도로 그리며, 설정에서 끌 수 있습니다 (퀘스트에서 무거우면 끄기).

더미는 첨부된 테스트 더미 모델을 씁니다. 맞으면 날아가고, 쓰러지면 일어나며, 죽으면 파편으로 부서지거나 참격 방향대로 잘립니다.
**잡기·던지기**: 더미에 손을 대고 주먹을 쥐면 손에 가장 가까운 부위(머리·팔·다리 등)를 잡고, 나머지 몸은 래그돌 물리로 늘어지고 흔들립니다. 손을 펴면 손의 속도로 던집니다 (컨트롤러: 그립, 데스크톱: T). 기술에 맞아 날아갈 때도 래그돌로 움직입니다.

## 캐릭터

### 고죠 사토루 — 무하한 주술 · 육안

| 기술 | 핸드트래킹 | 컨트롤러 |
|---|---|---|
| 術式順転「蒼」 | 검지+중지로 가리키면 손가락 끝에 생성 → **손을 펴면** 창이 손을 따라 멀리 이동 | 왼쪽 트리거 |
| 術式反転「赫」 | 검지만 펴서 충전 → 찌르거나 손을 펴서 발사 | 오른쪽 트리거 충전 → 놓기 |
| 전환 · 취소 | 창 상태에서 검지만 → 혁, 혁 상태에서 검지+중지 → 창 · **주먹 → 사라짐** | — |
| 虚式「茈」 | **수인**: 검지·중지를 접고 그 위에 엄지를 얹은 채 약지·새끼를 펴기 → 왼쪽의 창과 오른쪽의 혁이 곧게 다가와 합쳐져 茈 완성 → 손을 펴거나 밀면 발사, 주먹은 취소 (양손 창+혁을 맞대도 됨) | 창+혁 유지, 컨트롤러 맞대기 → 밀기/놓기 |
| 領域展開「無量空処」 | 검지·중지만 펴서 **얼굴 앞에 세우고 6초** — 1초째부터 영창 음성이 나오고 끝날 즈음 전개 (설정에서 끄기 / 메뉴에서 발동) | 양쪽 스틱 눌러 6초 |
| 無下限 / 六眼 | 양 손바닥 앞으로 1초 / 손으로 눈을 0.5초 가리기 (추적이 끊겨도 인식) | X / A |

무량공처 연출: 결계 돔 → 화이트아웃 → 정면(좌우 방향만 따름)에서 날아오는 초공간 워프 → 섬광 → 하얀 빛을 두른 블랙홀과, 영역(구)의 겉면에서 계속 사라졌다 다시 튀는 하얀 물감 얼룩. 영역 안의 더미와 탄환은 멈춥니다. 영역전개 후 10초 재사용 대기.

### 료멘 스쿠나 — 어주자(御廚子)

| 기술 | 핸드트래킹 | 컨트롤러 |
|---|---|---|
| 解(カイ) 참격 | 편 손을 빠르게 휘두르기 (연속 가능) | 트리거(정면) / 트리거 쥐고 휘두르기 |
| 捌(ハチ) 난도질 | 편 손으로 더미를 직접 건드리기 — 약한 상대일수록 잘게 썰림 | 더미에 대고 트리거 |
| 竈(カミノ) 開(フーガ) | 한 손을 펴고, 다른 손 집게로 그 앞을 잡아 활처럼 당겼다 놓기 | 왼쪽 그립 + 오른쪽을 왼손에 대고 트리거 → 당겼다 놓기 |
| 세계를 가르는 해 | 편 손바닥을 앞으로 뻗고 1.3초(영창 龍鱗·反発·番いの流星) → 휘두르기 | A 1.3초 → 휘두르기 |
| 領域展開「伏魔御廚子」 | 얼굴 앞에서 손바닥을 마주 대고 손가락을 세워 1.5초 (메뉴에서도 발동) | 양쪽 스틱 눌러 1.5초 |

영역전개 시 영창 음성이 나오고, 음성이 끝나기 0.5초 전부터 영역 음악이 흐릅니다 (영역 20초).

세계참 영창과 영역전개 수인 중에는 먹선 테두리의 핏빛 오라가 손을 감싸고, 영창이 진행될수록 점점 선명해집니다 (컨트롤러는 컨트롤러를 감쌈). 개(開)의 화살은 당길수록 굵어지지 않고 길어집니다. 개(開)의 화살과 폭발은 실사풍 불(`src/core/realFire.js`: GPU 빌보드 불꽃·연기·불티, 흑체 색, 닫힌 식 운동)로 그립니다. 화살은 백열하는 심을 따라 불꽃이 핥으며 타오르고, 날아가면 불꼬리와 연기 자국을 남깁니다. 착탄하면 섬광 → 화구 → 불기둥 → 검은 연기·버섯구름 → 바닥 먼지 고리 → 불티 순으로 터지고, 바닥에 숯 같은 그을음과 잔불이 남습니다.

복마어주자는 첨부된 사당 모델이 플레이어 **뒤쪽**에 솟아오르며(뼈 무더기는 땅에 반쯤 묻힘), 안에서는 범위 안 모든 것이 해·팔에 계속 썰리고, 카미노를 쓰면 분진이 일제히 폭발합니다. 설정에서 **카미노 원작 조건**을 켜면 해와 팔을 먼저 써야 개(開)가 열립니다.

### 이타도리 유지 — 체술 · 흑섬 · 적혈조술 · 어주자

| 기술 | 핸드트래킹 | 컨트롤러 |
|---|---|---|
| 逕庭拳(경정권) | 주먹으로 치면 한 박자(0.13초) 늦게 주력이 한 번 더 터진다 — 모든 일반 타격이 2타 | 그립 쥐고 휘둘러 치기 |
| 黒閃(흑섬) | 손을 편 채 휘두르다 **닿기 직전에 주먹을 쥐면 확정**. 흑섬 뒤 8초는 존(흑섬 확률↑, 주력 회복↑), 연속 흑섬은 위력이 오르고 `N連続`이 뜬다 | 닿기 직전에 그립 |
| 御廚子「解」(어주자 해) | 검지·중지를 편 **가위 손**으로 더미를 건드리기 → 가위 문양과 점선 절취선이 그어지고 0.3초 뒤 싹둑 | 더미에 대고 A/X |
| 赤血操術「穿血」(천혈) | 두 손바닥을 맞대고 손끝을 앞으로 → 피가 압축(백렴) → 0.5초 이상 모은 뒤 **두 손을 떼면** 손끝 방향으로 관통하는 피의 광선 | 두 컨트롤러를 맞대고 양쪽 그립 → 하나 놓기 |
| 領域展開 | 한 손바닥을 위로 펴 가슴 앞에, 다른 손은 주먹을 세워 1.5초 (지장보살) · 메뉴에서도 발동 | 양쪽 스틱 1.5초 |

영역은 할아버지와 살던 동네(노을 진 주택가와 전봇대)가 솟아오르는 **필중만 있는 고전적인 영역**입니다. 16초 동안 안의 모든 대상에 영혼을 가르는 해가 돌아가며 떨어지고, 가위 손으로 0.25초 가리키기만 해도 해가 닿습니다. 흑섬 확률도 오릅니다. 원작 설정상 생득술식이 없어 손 모양은 대부분 맨손 동작입니다.

### 후시구로 메구미 — 십종영법술(十種影法術)

손으로 그림자놀이처럼 식신의 모양을 맺으면 바닥의 그림자 웅덩이에서 식신이 솟아오르고, 일을 마치면 다시 그림자로 가라앉습니다. **같은 수인을 다시 맺으면 그 식신을 돌려보냅니다.**

| 식신 | 수인 (핸드트래킹) | 하는 일 |
|---|---|---|
| 玉犬 옥견 白·黒 | 두 손을 같은 방향으로 포개 손끝을 앞으로 (개 머리) 0.35초 | 흰 개·검은 개가 대상 양옆에서 물어뜯는다 (네 번째엔 크게 물어 넘어뜨림) |
| 玉犬・渾 옥견 혼 | 옥견과 같은 수인 (옥견 하나가 **파괴된 뒤**) | 파괴된 옥견의 힘을 이어받은 두 발의 거대한 늑대. 좌우 발톱 연속 베기(세 줄 발톱 자국) → 덮쳐 내려찍기, 멀면 도약해 덮친다 |
| 鵺 누에 | 두 엄지를 걸고 손바닥을 내 쪽으로, 손가락을 날개처럼 | 머리 위를 맴돌다 전기를 두르고 내리꽂는다 |
| 蝦蟇 가마 | 두 손바닥을 위아래로 마주 보게 벌려 손끝을 앞으로 (두꺼비 입) | 혀로 바라본 대상을 붙잡아 플레이어 앞에 끌어다 떨군다 |
| 大蛇 오로치 | 한 손을 펴서 손끝으로 앞쪽 바닥을 가리키기 | 바라본 대상 발밑에서 솟아 물어 올리고, 조인 뒤 땅에 내리꽂는다 |
| 満象 만상 | 두 주먹을 모아 머리 위로 → 아래로 내려치기 | 바라본 대상 위 하늘의 그림자에서 떨어져 짓누르고, 코로 물을 뿜어 밀어낸다 |
| 脱兎 탈토 | 한 손 검지·중지를 얼굴 옆에서 토끼 귀처럼 세우기 | 토끼 수십 마리가 흩어져 뛰어다니고, 8초 동안 더미가 토끼를 노린다 (미끼) |
| 貫牛 관우 | 두 손 검지를 머리 옆에서 앞으로 세워 뿔처럼 (양손 사이를 벌린다) | 앞발로 땅을 긁다가 바라본 방향으로 **곧게만** 돌진 — 달린 거리만큼 기하급수적으로 빨라지고 세진다 |
| 八握剣 異戒神将 魔虚羅 마허라 | 주먹을 다른 손 손바닥에 대고 1초 (布瑠部由良由良) | 퇴마의 검(정의 에너지 궤적)으로 베어 가르고, **온갖 사상에 적응**한다 (아래). 조복 전엔 싸울 상대가 없으면 술사를 노린다 |
| 領域展開「嵌合暗翳庭」 | 두 손을 모아 깍지 끼고 손끝을 아래로, 허리 아래까지 내려 1.2초 | 바닥 전체가 그림자 바다 → 식신 소모·대기 없음, 식신이 사라지지 않음, 대상 발밑에서 그림자 송곳이 솟는다 (20초) |

컨트롤러: 왼쪽 트리거로 식신 고르기 → 오른쪽 트리거로 부르기, 양쪽 스틱 1.2초로 영역전개.

**식신 파괴**: 더미는 가까이서 싸우는 식신을 치고(주먹·총탄), 조복 의식 중인 마허라는 식신도 벱니다. 십종영법술의 식신은 파괴되면 다시 부를 수 없습니다 (누에·가마·관우·옥견 혼, 맵을 다시 시작하면 복구). 옥견이 파괴되면 남은 옥견이 힘을 이어받아 다음부터 옥견 수인으로 **玉犬・渾**이 나옵니다.

**마허라 — 적응**
- 맞은 공격의 성질(타격·충격·참격·총탄·전격·화염…)을 분석하고, 분석이 끝나면 머리 위 법진이 철컥 한 칸 돌며 **몸이 한순간에 완전히 재생**되고 그 성질의 피해가 크게 줄어듭니다 (단계마다 ×0.42). 같은 성질끼리는 내성을 절반쯤 나눠 가집니다 (타격을 익히면 충격도 어느 정도 버팀)
- 참격·충격에 적응하면 몸을 부풀려 피해를 더 줄이고, 술사가 칼을 두 번 피하면 **회피 패턴**에 적응해 더 멀리·빨리 벱니다. 벤 상대의 종류도 분석해 공략할수록 위력이 오릅니다
- 법진이 여덟 번 돌면 **무한회전** — 존재 그 자체에 적응해 모든 피해가 더 줄고 분석이 거의 즉시 끝납니다
- 이기는 방법은 하나: **적응해 재생하기 전에, 한 번에 체력을 넘는 위력으로 소멸**시키는 것 (예: 멀리서 달려온 관우, 만상, 처음 보는 성질의 공격)
- **조복 의식**: 조복 전의 마허라는 싸울 상대가 없으면 술사와 식신을 노리고, 이때 술사의 주먹·식신으로 칠 수 있습니다. 쓰러뜨리면 조복 완료 (설정에 저장, 설정의 '마허라 조복됨'으로 되돌리기)
- **조복 후**: 술사를 노리지 않습니다. 수인을 맺으면 먼저 **법진만** 머리 위에 떠서 술사가 받는 공격(더미 주먹·총탄)에 대신 적응하고 피해를 줄여 줍니다. 한 번 더 맺으면 그 적응을 그대로 이어받은 마허라가 나옵니다 (스쿠나의 운용법). 돌려보내면 쌓인 적응은 사라집니다. 조복한 마허라가 파괴되면 십종영법술이 기능을 잃습니다
- 손목 HUD에 마허라 체력과 지금까지의 적응이 보입니다

식신은 아래 3D 모델에 셀 셰이딩 + 먹선 테두리를 입혀 쓰고 (모델을 못 불러오면 코드로 만든 모델), 움직임은 모두 코드로 짭니다.
- **옥견**: 실제 네발짐승의 걸음새 — 걷기(뒷다리 → 같은 쪽 앞다리 순서), 속보(대각선 다리가 짝), 질주(회전 갤럽, 등을 굽혔다 펴며 네 발이 모두 뜨는 순간이 있다). 속도에 따라 부드럽게 바뀌고, 다리마다 지지/들기 구간이 따로 있다. 돌 때 몸을 기울이고, 뛰면 헐떡이며, 물 때는 앞다리로 버티고 머리를 낮게 내민다. 꼬리는 몸을 늦게 따라온다
- **누에**: 새의 날갯짓 — 빠른 내려치기(날개를 활짝 펴고 앞으로 쓸며) → 느린 올려치기(팔꿈치·손목을 접어 날개 폭을 줄이고 깃을 비튼다). 깃 끝은 공기에 밀려 늦게 휜다. 순항 땐 몇 번 치고 미끄러지듯 활공하고, 오를 땐 쉬지 않고 크게 친다. 내리꽂을 땐 날개를 접어 몸에 붙였다가, 낚아채기 직전 날개를 앞으로 펼쳐 제동하며 발톱을 내민다. 돌 땐 몸을 눕히고, 몸이 흔들려도 머리는 제자리
- **관우**: 앞발로 땅을 긁어 흙을 튀기다가 갤럽으로 돌진, 멈출 땐 앞다리를 내뻗어 버티며 미끄러진다
- **만상**: 떨어지며 다리를 벌리고 귀가 바람에 들린다. 착지하면 무게에 무릎이 꺾여 내려앉았다 출렁이고, 귀·코·꼬리가 관성으로 늦게 휘청인다
- **마허라**: 무거운 두 발 걸음 (골반 비틀림·처짐, 착지 충격으로 철렁, 팔은 다리와 엇갈려), 내려베기는 예비동작(칼을 치켜들며 몸을 감기) → 왼발을 내딛으며 대각선으로 → 이어베기 → 회복
- **가마**: 혀를 쏘기 전 웅크리고, 쏠 때 앞으로 튀어나가듯 숙이고, 끌어올 땐 뒤로 버티며 떤다. 목주머니가 벌렁인다
- **오로치**: 몸을 따라 흐르는 S자 물결, 물어 올린 대상을 몸통으로 나선처럼 휘감아 조인다
- **탈토**: 뛰기 전 웅크리고, 공중에선 늘어나며 코를 들었다 내리고, 착지하면 납작해졌다 출렁인다
- **옥견 혼**: 상체를 숙인 두 발 걸음(빨라지면 보폭·앞기울기가 커지고 공중에 뜬다), 팔을 높이 치켜들었다 대각선으로 내리긋는 발톱, 웅크렸다 뛰어올라 두 팔로 내려찍기

### 공통
- **주먹**: 주먹(컨트롤러는 그립)으로 더미를 치면 타격. 주술회전 캐릭터는 일정 확률로 **흑섬(黒閃)** — 히트스톱과 검붉은 번개. 오공은 기를 실은 충격파, 구미 모드·초사이어인은 위력 2배

- 기술을 쓰면 만화풍 일본어 기술명이 뜹니다 (설정에서 끄기 가능)

## 실행

WebXR은 **HTTPS**에서만 동작합니다.

- **GitHub Pages**: 저장소 Settings → Pages → `Deploy from a branch`, `main` / `(root)` → `https://<사용자명>.github.io/animevr/`
- **로컬**: `npx serve .` 또는 `python3 -m http.server 8080` 후 PC 브라우저(데스크톱 모드). Quest에서 로컬로 보려면 USB 연결 후 `adb reverse tcp:8080 tcp:8080`

손·컨트롤러 모델은 Meta Quest 기본 모델(WebXR Input Profiles, MIT)을 `assets/profiles`에 포함해 오프라인에서도 보입니다.

## 소리

- `assets/audio/sfx/`: 기술 효과음. `python3 tools/gen_sfx.py`로 다시 만들 수 있습니다 (잡음·과도음·잔향을 겹쳐 렌더링). 이름을 붙이면 그 파일만 다시 씁니다 (예: `python3 tools/gen_sfx.py poof ki_blast`). `slash.mp3`(스쿠나 참격)는 사용자가 제공한 파일입니다.
- `assets/audio/`: 영역전개 음성(고죠·스쿠나), 푸가 음성, 복마어주자 음악 — 사용자가 제공한 파일을 압축해 넣은 것입니다. 원작 음원은 저작권이 있으니 저장소를 공개 배포할 때는 주의하세요.

## 캐릭터 추가하기

`src/characters/<id>/`에 클래스를 만들고 `constructor(ctx)`, `update(dt)`, `dispose()`, `helpLines(mode)`, `hudRows()`를 구현한 뒤 `src/characters/index.js`의 `CHARACTERS`에 등록합니다. `ctx.input.left/right`에서 손 모양(`gesture`, `gestureTime`), 위치·방향·속도(`pos`, `dir`, `palm`, `vel`, `speed`), 버튼(`btn`, `pressed()`)을 읽고, `ctx.world.forEachTarget()`으로 더미와 소품에 `impulse()`·`damage()`를 주면 됩니다. 선택: `meleeHit()`(주먹 타격을 직접 처리), `castDomain()`·`cancelDomain()`·`domainLabel`(영역전개 자리의 궁극기), `reviveText`(쓰러졌을 때 문구), `handBusy(side)`(잡기 막기).
