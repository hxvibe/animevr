# ANIME VR — 술식 시뮬레이터

애니메이션 캐릭터의 기술을 직접 손으로 써보는 WebXR VR 시뮬레이터입니다.
더미를 원하는 만큼 소환해서 기술을 시험할 수 있습니다. 설치 없이 VR 기기(Meta Quest 등) 브라우저에서 바로 실행되며, **컨트롤러와 핸드트래킹을 모두 지원**합니다.

> 비공식 팬메이드 프로젝트입니다. 원작의 이미지·음원은 쓰지 않으며 그래픽과 효과음은 모두 코드로 만듭니다.

## 흐름

1. 첫 화면에서 **VR 시작** (또는 데스크톱으로 체험)
2. VR 안의 **타이틀 화면**에서 캐릭터와 배경을 고르고 **시작**
3. 게임 중 메뉴(옵션)는 **열었을 때만** 나타납니다: 컨트롤러 **Y** / 왼손바닥을 하늘로 / 키보드 **H**
   - **더미 소환**: 종류(기본·사격형·돌격형·거대·샌드백∞), 체력(50·100·300·1000·∞), 수량
   - **설정**: 배경(하얀 방·도시·골목), 손목 HUD, 기술명 표시, 데미지 숫자, 플레이어 무적, 스틱 이동, 카미노 원작 조건, 높이 보정
   - **조작법**, **메인 메뉴**
4. **B 버튼 / R 키**: 선택한 더미를 바로 소환

더미는 SUPERHOT VR처럼 붉은 유리질 인간형입니다. 맞으면 날아가고, 쓰러지면 일어나며, 죽으면 파편으로 부서지거나 참격 방향대로 잘립니다.

## 캐릭터

### 고죠 사토루 — 무하한 주술 · 육안

| 기술 | 핸드트래킹 | 컨트롤러 |
|---|---|---|
| 術式順転「蒼」 | 검지+중지로 앞을 가리키고 유지 (팔을 뻗을수록 멀리) | 왼쪽 트리거 |
| 術式反転「赫」 | 검지만 펴서 충전 → 찌르거나 손을 펴서 발사 | 오른쪽 트리거 충전 → 놓기 |
| 虚式「茈」 | 창+혁 상태로 두 손끝을 맞대기 → 밀거나 손을 펴서 발사 | 창+혁 유지, 컨트롤러 맞대기 → 밀기/놓기 |
| 領域展開「無量空処」 | 검지·중지 교차, 또는 두 손가락을 하늘로 세우고 1초 | 양쪽 그립 1초 |
| 無下限 / 六眼 | 양 손바닥 앞으로 1초 / 눈을 가렸다 떼기 | X / A |

무량공처 연출: 결계 돔과 별 문양 → 하늘에 떠오르는 육안 → 화이트아웃 → 초공간 워프 → 섬광 → 블랙홀이 뜬 우주. 영역 안의 더미와 탄환은 멈춥니다.

### 료멘 스쿠나 — 어주자(御廚子)

| 기술 | 핸드트래킹 | 컨트롤러 |
|---|---|---|
| 解(カイ) 참격 | 편 손을 빠르게 휘두르기 (연속 가능) | 트리거(정면) / 트리거 쥐고 휘두르기 |
| 捌(ハチ) 난도질 | 편 손으로 더미를 직접 건드리기 — 약한 상대일수록 잘게 썰림 | 더미에 대고 트리거 |
| 竈(カミノ) 開(フーガ) | 한 손을 펴고, 다른 손 집게로 그 앞을 잡아 활처럼 당겼다 놓기 | 왼쪽 그립 + 오른쪽을 왼손에 대고 트리거 → 당겼다 놓기 |
| 세계를 가르는 해 | 편 손바닥을 앞으로 뻗고 1.3초(영창 龍鱗·反発·番いの流星) → 휘두르기 | A 1.3초 → 휘두르기 |
| 領域展開「伏魔御廚子」 | 얼굴 앞에서 양손을 맞대고 1.2초 | 두 컨트롤러를 모으고 양쪽 그립 1.2초 |

복마어주자 안에서는 범위 안 모든 것이 해·팔에 계속 썰리고, 카미노를 쓰면 분진이 일제히 폭발합니다. 설정에서 **카미노 원작 조건**을 켜면 해와 팔을 먼저 써야 개(開)가 열립니다.

### 공통
- **흑섬(黒閃)**: 주먹(컨트롤러는 그립)으로 더미를 치면 타격, 일정 확률로 흑섬 — 히트스톱과 검붉은 번개
- **반전술식**: 피격 2초 뒤부터 체력 자동 회복
- 기술을 쓰면 만화풍 일본어 기술명이 뜹니다 (설정에서 끄기 가능)

### 데스크톱 (VR 없이 테스트)
화면 클릭으로 마우스 고정, WASD 이동, H/Tab 메뉴, R 더미 소환, V 주먹.
고죠: 우클릭 창 · 좌클릭 혁 · 둘 다 누르고 E → 놓기 茈 · Q 영역 · I/O 토글.
스쿠나: 좌클릭 해 · 우클릭 팔 · F 개 · G 영창 후 좌클릭 세계참 · Q 영역.

## 실행

WebXR은 **HTTPS**에서만 동작합니다.

- **GitHub Pages**: 저장소 Settings → Pages → `Deploy from a branch`, `main` / `(root)` → `https://<사용자명>.github.io/animevr/`
- **로컬**: `npx serve .` 또는 `python3 -m http.server 8080` 후 PC 브라우저(데스크톱 모드). Quest에서 로컬로 보려면 USB 연결 후 `adb reverse tcp:8080 tcp:8080`

손·컨트롤러 모델은 Meta Quest 기본 모델(WebXR Input Profiles, MIT)을 `assets/profiles`에 포함해 오프라인에서도 보입니다.

## 구조

```
index.html                       첫 화면, three.js import map (CDN)
src/main.js                      렌더러 · XR 세션 · 게임 흐름(타이틀/시작) · 메인 루프
src/core/input.js                컨트롤러/핸드트래킹/데스크톱 → HandState (손 모양, 속도, 버튼)
src/core/gestures.js             손 관절 25개로 손 모양 판별 (굽힘 각도 + 직선도)
src/core/world.js                더미 · 파괴 가능한 소품 · 탄환 · 플레이어
src/core/dummy.js                SUPERHOT풍 인간형 더미 (종류별 AI)
src/core/slicer.js               클리핑 평면 절단 조각 + 유리 파편
src/core/melee.js                주먹 타격 · 흑섬
src/core/ui.js                   타이틀/옵션 패널 · HUD · 만화풍 기술명 · 데미지 숫자
src/core/env/                    배경(하얀 방·도시·골목)과 절차적 텍스처
src/characters/gojo/             고죠 (기술 · 에너지 구체 · 무량공처)
src/characters/sukuna/           스쿠나 (기술 · 참격/화염 VFX · 복마어주자)
assets/profiles/                 Meta Quest 손·컨트롤러 모델
```

## 캐릭터 추가하기

`src/characters/<id>/`에 클래스를 만들고 `constructor(ctx)`, `update(dt)`, `dispose()`, `helpLines(mode)`, `hudRows()`를 구현한 뒤 `src/characters/index.js`의 `CHARACTERS`에 등록합니다. `ctx.input.left/right`에서 손 모양(`gesture`, `gestureTime`), 위치·방향·속도(`pos`, `dir`, `palm`, `vel`, `speed`), 버튼(`btn`, `pressed()`)을 읽고, `ctx.world.forEachTarget()`으로 더미와 소품에 `impulse()`·`damage()`를 주면 됩니다.
